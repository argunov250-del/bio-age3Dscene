# Демо-диалоги коуча Хирона

Дата генерации: 2026-11-06. Диалогов: 48 (русских 42, английских 6).

Файл создан скриптом `scripts/demoDialogs.js`, который вызывает настоящий движок (`reply()` из `lib/coachBrain.js`) на заранее заданных наборах данных и погоды. Ничего не вписано вручную: тексты ответов берутся из каталога как есть. Перегенерация из корня репозитория:

```
npx jest --config scripts/jest.demo.config.js
```

Документ нужен для ручной проверки характера коуча (тон, грамматика, повторы, уместность шуток) и не заменяет автоматические тесты. Внутри диалога движок получает память и историю предыдущих ходов, как в приложении.
