# Версии и метки изменений

## Как подписываем коммиты

**Мелкие изменения** — метка из букв затронутых областей и их счётчиков, например `i6c5`.
Счётчик буквы — сколько раз эту область меняли за всё время; он растёт только у затронутых
букв и никогда не сбрасывается. Порядок букв всегда: i, c, f, b, x.

| Буква | Область |
| --- | --- |
| i | интерфейс: экраны, анимации, цвета, тексты |
| c | код и логика: расчёт, чтение данных, хранение |
| f | формула: коэффициенты, исследования, нормы |
| b | сборка: workflow, иконка, разрешения, системный экран |
| x | исправление ошибки |

**Крупные обновления** — `Update 0.00.02.1 (33)`: номер версии и в скобках число файлов
в репозитории (`git ls-files | wc -l`). Только такие коммиты собирают APK
(или ручной запуск workflow в GitHub Actions).

В приложении внизу главного экрана: `Версия 0.00.02.0 · i10c3f1b5x2` — номер последнего
крупного обновления и все счётчики на момент сборки (`lib/version.js`).
