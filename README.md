# Epimely (прототип)

Epimely (от греч. epimeleia — «забота о себе») считает биологический возраст по данным Health Connect (по принципу WHOOP Age), следит за сном, восстановлением и тренировками, а наставник Хирон даёт советы офлайн. Только для своего телефона, не медицинский показатель.

## Сборка

Пуш в `main` коммита «Update …» (крупное обновление, см. `VERSION.md`) запускает `.github/workflows/build-apk.yml`; мелкие коммиты с метками вроде `i6c5` сборку не запускают. Сборка: создаётся пустой Expo-проект, в него копируются `App.js` и `lib/`, затем `npx expo prebuild --platform android` и `./gradlew assembleRelease`. APK — в артефакте запуска workflow `epimely-apk` (вкладки: Обзор, Метрики, Тренировки, Профиль). Аккаунт Expo не нужен. Expo Go не подойдёт: Health Connect работает только в нативной сборке.

Плагин Expo для Health Connect с версии 4 встроен в `react-native-health-connect`, отдельный `expo-health-connect` устарел и вместе с ним сборка падает на дублирующемся классе — поэтому подключён только `react-native-health-connect`. `minSdkVersion 26` задаётся через `expo-build-properties`.

## Разрешения

Только чтение: шаги, сон, пульс, пульс в покое, тренировки, VO2max, безжировая масса. Плюс `READ_HEALTH_DATA_HISTORY` — без него Health Connect отдаёт данные только за 30 дней до первой выдачи доступа, а расчёт идёт по 6 месяцам.

## 3D-сцена

Фон вкладок — живая 3D-сцена: выдуманное дерево в каменном кольце (`scene/src`, three.js). Она работает в `react-native-webview` без интернета: весь код собран в один HTML и лежит в `lib/scene3d/sceneHtml.js`.

- **Запуск.** Чистый лист → дерево рисуется карандашом → рисунок становится живым → поверх проявляется «Обзор». Это один холст и один непрерывный кадр (`lib/screens/SceneLaunch.js` только ведёт шаги).
- **Вкладки.** Свайп влево/вправо переключает вкладку, сцена поворачивается за пальцем на 1/5 круга; с последней вкладки свайп ведёт дальше по кругу — к первой.
- **Сезон и погода** (`lib/sceneState.js`). Зима по календарю — снежная сцена (снег идёт, только если он идёт за окном), март — оттепель, весной дерево цветёт, летом зелень, осенью листва желтеет и опадает. С включённой погодой: дождь, гроза с молниями, снегопад, туман, облака, ветер, день и ночь.
- **Настройки.** «Профиль → 3D-сцена с деревом на фоне». Если WebView не смог показать сцену, приложение само возвращается к прежнему запуску и фону. На Android 10 и старше сцена упрощена.

Изменить сцену: `cd scene && npm install && npm run preview` (откройте `scene/preview.html` в браузере; параметры — в адресе, например `#dark=true&period=night&precip=snow&snow=1`), затем `npm run build` и закоммитьте `lib/scene3d/sceneHtml.js`.

## Расчёт

Для каждой метрики hazard ratio смертности из исследований переводится в годы: `годы = ln(HR) / ln(1.10)` (+10% риска ≈ +1 год). Биологический возраст = паспортный + сумма поправок за последние 6 месяцев. Похожие метрики перекрываются: внутри группы вторая по величине поправка идёт с весом 1/2, третья — 1/3 и т. д. Итог ограничен −10…+15 лет. Темп старения сравнивает последние 30 дней с полугодием. Подробности — в комментариях `lib/formula.js`.

## Приватность

Никаких серверов, аккаунтов, аналитики и рекламы. Данные о здоровье не покидают телефон. Интернет используется только для погоды, если включить её в профиле: в Open-Meteo уходят координаты, округлённые до ~10 км, или выбранный город (`lib/weather.js`). Коуч работает офлайн: база знаний из рекомендаций ВОЗ и исследований вшита в приложение (`lib/knowledge.js`), ответы составляются на телефоне (`lib/coachBrain.js`).

## Импорт

«Профиль → Импорт и резервная копия»: экспорт «Здоровья» с iPhone (export.zip читается потоком, `lib/importer.js` + `lib/appleHealth.js`, последние 6 месяцев, дополняет Health Connect там, где за период нет данных), таблица CSV (в ручные записи), резервная копия Epimely (JSON: профиль, записи, импорт; сохраняется через «Поделиться»).
