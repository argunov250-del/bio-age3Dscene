# Epimely (прототип)

Epimely (от греч. epimeleia — «забота о себе») считает биологический возраст по данным Health Connect (по принципу WHOOP Age), следит за сном, восстановлением и тренировками, а наставник Хирон даёт советы офлайн (по правилам, без ИИ-модели). Только для своего телефона, не медицинский показатель.

## Сборка

Пуш в `main` коммита «Update …» (крупное обновление, см. `VERSION.md`) запускает `.github/workflows/build-apk.yml`; мелкие коммиты с метками вроде `i6c5` сборку не запускают. Сборка: создаётся пустой Expo-проект, в него копируются `App.js` и `lib/`, затем `npx expo prebuild --platform android` и `./gradlew assembleRelease`. APK — в артефакте запуска workflow `epimely-apk` (вкладки: Главная, Здоровье, Прогресс, Профиль). Аккаунт Expo не нужен. Expo Go не подойдёт: Health Connect работает только в нативной сборке.

Плагин Expo для Health Connect с версии 4 встроен в `react-native-health-connect`, отдельный `expo-health-connect` устарел и вместе с ним сборка падает на дублирующемся классе — поэтому подключён только `react-native-health-connect`. `minSdkVersion 26` задаётся через `expo-build-properties`.

## Разрешения

Только чтение: шаги, сон, пульс, пульс в покое, тренировки, VO2max, безжировая масса. Плюс `READ_HEALTH_DATA_HISTORY` — без него Health Connect отдаёт данные только за 30 дней до первой выдачи доступа, а расчёт идёт по 6 месяцам.

## 3D-сцена

Фон вкладок — живой горный мир (`scene/src`, three.js): собственная география по мотивам Эльбруса и Кавказа — двуглавая снежная вершина над морем облаков и дальние хребты, без построек. Сцена работает в `react-native-webview` без интернета: весь код собран в один HTML и лежит в `lib/scene3d/sceneHtml.js`.

- **Запуск.** Камера выходит из облаков и летит к вершине: при первом запуске — долгий пролёт, дальше — быстрое возвращение. Один холст и один непрерывный кадр (`lib/screens/SceneLaunch.js` только ведёт шаги).
- **Вкладки.** Главная — панорама двуглавой вершины, Здоровье — скалы и ледник вблизи, Прогресс — хребты с высоты, Профиль — долина над облаками. Переход — плавный облёт (свайп ведёт мир за пальцем, с последней вкладки — дальше по кругу к первой). В покое камера медленно парит.
- **Главная.** Сначала почти чистый пейзаж; свайп вверх раскрывает панель с показателями, свайп вниз по «ручке» сворачивает.
- **Погода, время суток, сезон** (`lib/sceneState.js`). Дождь, гроза с молниями, снегопад, туман, облака, ветер, день и ночь — как за окном (если погода включена), с плавным переходом. Зимой горы в снегу, весной граница снега поднимается, летом снег только на вершинах и зеленеют луга, осенью луга рыжеют. Без сети — по сезону, с пометкой на «Главной».
- **Хирон.** Без отдельной вкладки и без ИИ-модели: наставник в карточках (совет дня, задания, «Совет на сегодня»), советы — по правилам `lib/recommend.js` и `lib/coachBrain.js`.
- **Производительность.** В покое 30 кадров в секунду, при медленных кадрах разрешение сцены снижается само; на Android 10 и старше сцена упрощена; в фоне и на других экранах не рисуется. Выключается в «Профиль → 3D-сцена гор на фоне»; если WebView не смог показать сцену — прежний запуск и фон.

- **Вершины** (`lib/peaks.js`). Хребет дисциплины — за серию успешных дней подряд, Хребет постоянства — за общее число успешных дней. Успешный день — три и больше выполненных задания; день отдыха серию не рвёт; открытые вершины остаются навсегда. Новая вершина — пролёт камеры; долгий перерыв — дымка на дальних хребтах.
- **Спокойствие.** «Побыть в горах» на «Главной»: интерфейс уходит, остаются горы и звуки; 3–15 минут или без ограничения.
- **Звук.** Ветер, дождь и гром синтезируются в сцене (`scene/src/sound.js`), файлов и музыки нет; выключается в профиле.
- **Защита** (`lib/appLock.js`). Блокировка отпечатком, лицом или кодом телефона, запрет снимков экрана, гостевой режим (видны только горы).

Изменить сцену: `cd scene && npm install && npm run preview` (откройте `scene/preview.html` в браузере; параметры — в адресе, например `#dark=true&period=night&precip=snow&snow=1`), затем `npm run build` и закоммитьте `lib/scene3d/sceneHtml.js`.

## Расчёт

Для каждой метрики hazard ratio смертности из исследований переводится в годы: `годы = ln(HR) / ln(1.10)` (+10% риска ≈ +1 год). Биологический возраст = паспортный + сумма поправок за последние 6 месяцев. Похожие метрики перекрываются: внутри группы вторая по величине поправка идёт с весом 1/2, третья — 1/3 и т. д. Итог ограничен −10…+15 лет. Темп старения сравнивает последние 30 дней с полугодием. Подробности — в комментариях `lib/formula.js`.

## Приватность

Никаких серверов, аккаунтов, аналитики и рекламы. Данные о здоровье не покидают телефон. Интернет используется только для погоды, если включить её в профиле: в Open-Meteo уходят координаты, округлённые до ~10 км, или выбранный город (`lib/weather.js`). Коуч работает офлайн: база знаний из рекомендаций ВОЗ и исследований вшита в приложение (`lib/knowledge.js`), ответы составляются на телефоне (`lib/coachBrain.js`).

## Импорт

«Профиль → Импорт и резервная копия»: экспорт «Здоровья» с iPhone (export.zip читается потоком, `lib/importer.js` + `lib/appleHealth.js`, последние 6 месяцев, дополняет Health Connect там, где за период нет данных), таблица CSV (в ручные записи), резервная копия Epimely (JSON: профиль, записи, импорт; сохраняется через «Поделиться»).
